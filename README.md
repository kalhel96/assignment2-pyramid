# The Egyptian Pyramids

A two-page educational website about the Egyptian pyramids, built with semantic HTML, custom CSS, and Bootstrap 5.

**Live site:** https://kalhel96.github.io/assignment2-pyramid/

## Pages
- `index.html`: Home page (what the pyramids are, famous pyramids, how they were built)
- `page2.html`: Pyramid facts and FAQ

## Built with
- HTML5 (semantic structure and accessibility)
- CSS3 (custom styles and media queries)
- Bootstrap 5.3 (grid, buttons, spacing)
